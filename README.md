# 누가 나 먹었어? - Monster Team Randomizer

괴물에게 먹힌 곳이 내 모둠! 수업과 행사에서 쓰는 **랜덤 모둠 편성 게임**입니다.

명단을 넣고 START를 누르면 학생들이 경기장에서 도망다니고, 괴물들이 학생을 먹고, 서로 싸우고, 토해냅니다.
제한 시간 동안 팀은 계속 바뀌고, 시간이 끝나면 **모든 모둠의 인원 차이가 최대 1명**이 되도록 공평하게 확정됩니다.

## 사용 방법

1. 참가자 명단을 한 줄에 한 명씩 붙여넣습니다. (엑셀·한글 명단 그대로 가능, 번호만 써도 됨)
2. 괴물 수(= 모둠 수)를 2~6마리 중에서 고르고, 괴물 이름을 적습니다. (비워두면 ‘괴물 1’)
3. 게임 시간 30 / 60 / 90 / 120초 중 하나를 고릅니다. (기본 60초)
4. **START GAME**을 누릅니다.
5. 결과 화면에서 **결과 복사**를 누르면 모둠 명단이 텍스트로 복사됩니다.

- 화면을 한 번 클릭하면 음악과 효과음이 나옵니다. 오른쪽 아래 버튼으로 음악만 끌 수 있습니다.
- 마지막으로 쓴 명단과 설정은 그 컴퓨터의 브라우저에 저장됩니다.
- 설치할 것이 없습니다. `index.html` 파일 하나로 동작하며, 인터넷이 없으면 글꼴만 기본 글꼴로 바뀝니다.

## 공정성

- 모든 괴물은 외형만 다르고 속도·먹는 거리 등 능력은 같습니다.
- 게임 중에는 인원이 적은 괴물이 아주 조금 유리해지는 보정이 들어갑니다. (화면에는 표시하지 않음)
- 시간이 끝나면 게임이 인원을 다시 검사하고, 필요하면 *LAST STOMACH SHUFFLE*로 마지막 인원을 맞춥니다.
- 매 판마다 새 난수를 쓰므로 같은 명단으로 다시 해도 결과가 달라집니다.

## 수치 바꾸기

`index.html` 안의 `const CFG = { ... }` 한 곳에서 괴물 속도, 싸움 확률, 토하는 인원, 시간별 템포 등을 바꿀 수 있습니다.

## GitHub Pages로 공개하기

1. 이 저장소의 **Settings → Pages**로 이동합니다.
2. **Source**: `Deploy from a branch`, **Branch**: `main` / `/ (root)` 를 고르고 **Save**를 누릅니다.
3. 1~2분 뒤 `https://<사용자이름>.github.io/monster-team-randomizer/` 주소로 열립니다.
